# Terminal

Terminal mode shows the unmodified native OMP TUI in the editor tab, with Nerd Font glyphs, links and clickable file paths. Prefer the OMP terminal? Use OMP Desk as a host for native OMP terminals that survive reloads.

![Terminal mode](../../media/readme/terminal.png)

## Chat or Terminal in one tab

- **Switch to Chat** and **Switch to Terminal** in the editor title change the view of the same session.
- New sessions open in Chat. Choose Terminal for all new sessions with **OMP Desk: Choose Default Session View…**.
- Sessions open in their own editor group on the left; see [Where sessions and files open](sessions.md#where-sessions-and-files-open).

## In the Terminal

- Web links drawn by OMP open the same way as in [Chat](chat.md#links-to-files-code-symbols-and-the-web): in a VS Code editor tab on click, in your browser on `Ctrl+Click`.
- **Copy screen** and **Redraw Terminal** (`Ctrl+Alt+Shift+R`) are in the editor title menu.
- Theme changes recolor the terminal without restarting it.
- A Terminal session's OMP process ends with a VS Code update, unlike a Chat on Bun; see [the VS Code update exception](sessions.md#the-vs-code-update-exception).
