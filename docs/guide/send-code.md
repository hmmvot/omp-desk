# Send code to a session

- Select code and press `Alt+Shift+K`, or use **Add Selection to Session** or **Add File to Session** from the editor, Explorer or tab context menu.
- Pick the session. OMP Desk inserts an `@path` reference into its Chat or Terminal, with lines for a selection.
- It never sends the prompt for you.

`Alt+Shift+K` works in a text editor with a selection; see [Keyboard shortcuts](keyboard-shortcuts.md). To put the selected text itself into a Chat draft as a quote, with its file and lines, use `Alt+Q` or **Quote Selection to Session**; see [quoting Chat text](chat.md#quoting-chat-text).
